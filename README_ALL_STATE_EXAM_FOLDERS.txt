ALL STATE / UT EXAM FOLDER DIRECTORY

Added main folders for all 28 Indian states and 8 Union Territories.
Inside them, major state recruitment/exam sub-folders are pre-created as empty shells.
No passages were added in this batch.
New directory entries are FREE by default (paid_enabled=0); Owner can apply sub-folder payment conditions later.
Existing site features and existing exam/payment/result logic were kept intact.
The directory uses INSERT OR IGNORE, so existing exams are not overwritten when the server starts with an existing persistent database.
