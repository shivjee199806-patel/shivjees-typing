EXAM-LEVEL QUALIFICATION OWNER CONTROL

Added Owner authority to set qualification separately for every exam folder.
Conditions available:
- Required WPM
- Required Accuracy %
- Minimum Words
- Minimum Characters
- Qualification Method: WPM only / Accuracy only / WPM+Accuracy / Words+WPM+Accuracy / Characters+WPM+Accuracy / All enabled conditions

Rule: For exam/live attempts, exam-level qualification conditions are authoritative across all passages and language variants in that exam folder. If every required selected condition is met => Qualified; otherwise => Not Qualified.

Example: 450 minimum words + 30 WPM + 85% accuracy. If any one fails, status is Not Qualified.
